## 🚀 Introduction

**MemeLauncher** is a lightweight and powerful Android launcher designed for **Minecraft: Bedrock Edition**. It empowers players with advanced version management, native mod support, and seamless content integration, all within a clean and modern user interface.

Whether you want to run multiple versions of the game side-by-side, experiment with native SO modules, or easily manage your worlds and packs, MemeLauncher provides the ultimate toolkit for the mobile Bedrock community.

## ✨ Key Features

### 🎮 Version & Launch Management
- **Installation-Free Launching**: Import Minecraft APKs/APKS and run them directly without standard system installation.
- **Multi-Version Isolation**: Maintain multiple game versions independently. Each instance has its own isolated settings, worlds, and mods.
- **Quick Launch**: Launch directly into servers, worlds, or specific UI screens using custom URI protocols (`minecraft://`).

### 🛠️ Modding & Customization
- **CurseForge Integration**: Browse, search, and download Bedrock-specific Addons, Worlds, and Texture Packs directly from CurseForge.
- **Native Module Loading**: Load external `.so` modules to extend game functionality with high performance.
- **Inbuilt Mods**: Access a suite of useful internal mods like FPS/CPS displays, Quick Perspective, Auto Sprint, and more.

### 📦 Content Management
- **Universal Importer**: Seamlessly import `.mcworld`, `.mcpack`, and `.mcaddon` files.
- **Storage Flexibility**: Switch between Internal, External, and Version-Isolated storage for your game data.
- **Backup & Export**: Easily back up worlds or export content to share with others.

### 👤 Account & Social
- **Multi-Account Manager**: Store and switch between multiple Xbox/Microsoft accounts effortlessly within the launcher.
- **Real-time Logs**: Built-in Logcat overlay for developers and power users to debug issues on the fly.

## 📋 System Requirements

- **OS**: Android 9.0 (API 28) or higher.
- **Architecture**: ARM64 (v8a).
- **Storage**: At least 2GB of free space.
- **Requirement**: Must own a licensed copy of Minecraft.

## 🛠️ Build from Source

If you wish to build MemeLauncher yourself:

1. Clone the repository: `git clone https://github.com/BiniFn/MemeLauncher.git`
2. Open the project in **Android Studio (Ladybug or newer)**.
3. Add your CurseForge API key to `local.properties`:
   ```properties
   curseforge.api_key=YOUR_KEY_HERE
   ```
4. Build the project using the Gradle wrapper: `./gradlew assembleDebug`
